OS Concept Mapping: Process Management (CO2)

In an operating system, a Process is a program in execution. Here, each student attending the 3-hour examination is mapped to a process holding resources (Desk/Seat, Question Paper, Hall). The Process Control Block (PCB) stores state information: Process ID, Student Name, Memory Reference, and Scheduling State.
